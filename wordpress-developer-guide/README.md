## How it is meant to be used

Every chapter follows the same structure, so any topic can be revised on its own:

- **CODE** — copy-paste ready examples, with the comments written in Roman Urdu inside the code
- **INTERVIEW QUESTION** — the question as an interviewer would actually ask it
- **Practice test** — at the end of each chapter, with the answer key at the back

It is written to be read in sequence, beginner through to intermediate and advanced, but each chapter stands on its own for revision.
